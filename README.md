# Wired Mind — демонстрационный блог на Laravel

Минимальное приложение: публичный блог с постраничным списком постов и административная панель для управления постами, тегами и их видимостью.

## Стек

- **Laravel 13** на **PHP 8.5** (PHP-FPM)
- **MySQL 8.4**
- **Redis 7.4** — хранение сессий и кэша Laravel
- **Nginx**
- **Tailwind CSS 4** + Vite (собирается внутри Docker-образа)

## Быстрый старт

Нужны только Docker и Docker Compose:

```bash
docker compose up -d --build
```

Откройте **http://localhost:8080**.

При первом запуске контейнер `app` дожидается MySQL, применяет миграции и засевает демо-данные: 30 постов, 8 тегов, один администратор.

Админка: **http://localhost:8080/login**

| Логин | Пароль |
| --- | --- |
| `admin@example.com` | `password` |

Порт по умолчанию — 8080. Его можно изменить:

```bash
APP_PORT=8000 docker compose up -d --build
```

или создать `.env` в корне проекта с `APP_PORT=8000`.

Сеть Compose использует фиксированную подсеть `172.30.0.0/24`. Если она занята на вашей машине, поменяйте её в `docker-compose.yml` в блоке `networks.app.ipam`.

## Сервисы

| Сервис | Образ | Назначение | Порт |
| --- | --- | --- | --- |
| `web` | nginx:1.29-alpine | Отдаёт статику и проксирует PHP | `${APP_PORT:-8080}` → 80 |
| `app` | php:8.5-fpm-alpine | Приложение (php-fpm, pdo_mysql, opcache, redis) | — |
| `mysql` | mysql:8.4 | База данных | внутри сети |
| `redis` | redis:7.4-alpine | Сессии (db 0) и кэш Laravel (db 1) | внутри сети |

Данные MySQL и Redis хранятся в именованных томах `mysql-data` и `redis-data` и переживают перезапуск контейнеров.

## Маршруты

| URL | Описание |
| --- | --- |
| `/` | Постраничный список опубликованных постов |
| `/posts/{id}` | Страница поста (скрытые отдают 404) |
| `/tags/{id}` | Посты с выбранным тегом |
| `/login` | Вход в админку |
| `/admin/posts` | Список всех постов, публикация/скрытие, редактирование, удаление |
| `/admin/tags` | Создание, переименование и удаление тегов |

## Демо-данные

- 30 коротких постов на русском в духе референса, 4 из них скрыты — удобно проверить фильтр видимости.
- 8 тегов, у каждого поста от одного до трёх.
- Сидер постов выполняется только на пустой таблице `posts`: изменения, сделанные в админке, не перезаписываются при перезапуске контейнера.
- Полный сброс с повторным заполнением: `make fresh` (удалит все изменения).

## Команды

```bash
make up       # собрать и запустить
make down     # остановить
make logs     # логи всех сервисов
make shell    # shell внутри PHP-контейнера
make fresh    # migrate:fresh + seed
make test     # PHPUnit (запускается в отдельном composer-контейнере)
make pint     # форматирование PHP-кода
```

Эквивалент без make:

```bash
docker compose exec app php artisan route:list
docker compose exec app php artisan migrate:fresh --seed
```

## Тесты

```bash
make test
```

Покрыто: видимость постов в списке и на странице поста, пагинация, фильтр по тегу, создание/редактирование/удаление постов и тегов, переключение видимости, вход и выход. Тесты используют SQLite в памяти и не затрагивают демо-базу.


## Особенности демо

- Нет регистрации, восстановления пароля, капчи, загрузки изображений и ролей — по условию задачи.
- Авторизация — стандартный Laravel-гард с сессией в Redis и одним сидированным пользователем.
- `APP_KEY` и пароли в `docker-compose.yml` — демонстрационные. Для реального проекта их нужно вынести в секреты.
- Публичные страницы читают данные напрямую: для 30 постов кэширование не даёт выигрыша, поэтому Redis используется для сессий, а хранилище кэша готово к включению.
